# makefun-oneliners

One-line entries for make.fun's text bounties. Every entered commit of this
repository holds one line in [line.txt](line.txt); [main.ts](main.ts) is the
entrypoint the judge runs: it re-checks the line and copies it to `entry.txt`
in the sandbox's output directory.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
