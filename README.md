# makefun-oneliners

One-line entries for make.fun text bounties. Each bounty takes one text: the entry is the
single line in [line.txt](line.txt) at the entered commit, and [main.ts](main.ts) is the
entrypoint that validates it (UTF-8, 1-200 characters) and writes it to `entry.txt` in the
output directory.

## Run it

```sh
node main.ts   # writes /output/entry.txt; override the directory with MAKEFUN_OUTPUT_DIR
```
